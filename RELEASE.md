# ANetBBS v1.1.55 — Call log and activity log audit (October 2026)

Closes a long-standing gap where a web caller's session duration was permanently recorded as zero unless they used the explicit Logout link — the overwhelming majority of web sessions, which simply close the browser tab, never recorded a real duration before. Session duration is now backfilled from the existing daily stale-session cleanup job once an abandoned web session is reaped, using a new correlation between the presence-tracking table and the caller log.

Also closes a wide gap in the admin caller log drill-down, which was meant to show what a caller actually did during their session but was sparsely populated. Added activity logging across web echomail (viewing, posting, replying, deleting, netmail), web message boards (viewing, posting, replying), private message sending, QWK hub pack transfers, fifteen hub administration actions, and the terminal client's (both ANSI and PETSCII) echomail composing, inline reply, and private message sending — including a fourth, previously-unlogged local compose path reached only from inside the message reader. Also fixed existing file-download activity logging, on both the terminal client and the web file areas, so it correctly correlates to its caller log session and actually appears in the drill-down; the main web file-area download route had never logged a download at all before this.

A new shared `web_log_activity()` helper standardizes this logging for every web blueprint going forward. All new and modified logging was verified by reverting each fix and confirming its dedicated regression test fails for the right reason, and the full test suite (4,993 tests) passes clean.

Also fixes the online updater refusing to update at all on a system without the `sqlite3` command-line package installed — the pre-update database backup step now falls back to Python's built-in SQLite support (the same safe, WAL-consistent backup method, not a plain file copy) when that package isn't present, rather than aborting the update entirely.
