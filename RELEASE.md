# ANetBBS v1.1.54 — Telnet negotiation hardening and installer fix (October 2026)

Hardens the telnet protocol negotiation handler against malformed or oversized input: a subnegotiation sequence (used for terminal resize, terminal type, and similar protocol-level exchanges) is now bounded to a fixed maximum size and abandoned if it never completes, rather than being allowed to accumulate without limit while waiting for its terminator. Also fixes single-keystroke menu prompts so that telnet negotiation — most commonly a terminal-resize notification — can no longer be misread as a real keystroke, matching how text-entry prompts already handled it. Normal terminal-resize, terminal-type, MUD-protocol negotiation, and ordinary keyboard/arrow-key navigation are all confirmed unaffected by these changes. Separately, fixes the installer/updater's systemd unit generation so an install located under a user's home directory no longer risks failing to start after an update or fresh install; installs using the default system location are unaffected.
