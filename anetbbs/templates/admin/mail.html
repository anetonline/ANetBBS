Setup Checklist
  1. Point an MX record for the mail domain above at this server's public IP.
  2. Confirm inbound port 25 isn't blocked by your hosting provider -- common on cloud VPS and some ISPs.
  3. Configure the outbound relay at SMTP Relay Settings -- Internet Mail sends through that same relay, it does not need its own.
  4. Add an SPF TXT record authorizing whatever host that relay actually sends from (not this server's own IP).
  5. Enable the feature above once the systemd unit (anetbbs-mail) is installed and running.
