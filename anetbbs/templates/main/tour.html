Welcome Tour

A 60-second guide to {{ config.BBS_NAME }}.

1. Boards — threaded discussions
Read and post in topic-grouped boards. Replies thread under their parent so it's easy to follow conversations. Use @username to ping someone — they get an in-app notification.
Browse boards
2. Files — uploads and file echoes
File areas hold downloadable software, ANSI art, magazines, etc. Some areas accept uploads (sysop may queue them for approval first). Generate shareable links for friends without accounts.

3. Chat — MRC, IRC, real-time
Connect to the global MRC network (BBS-to-BBS), join IRC channels directly from your browser, or use the local shoutbox.

Tradewars, LORD, Usurper-style games — play in your browser via the web terminal. Some are built-in JS, others run as real DOS doors.
